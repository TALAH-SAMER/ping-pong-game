# Ping Pong Game 🏓

A simple two-player Ping Pong game built with Python and the Turtle graphics library as a training project while learning Python programming through Codezilla.

## About the Project

This project was implemented as part of my Python learning and training journey. I followed the project as a practical exercise to understand and practice Python programming concepts.

## Features

* Two-player gameplay
* Keyboard controls
* Ball movement and bouncing
* Paddle collision detection
* Boundary detection
* Graphical interface using Python Turtle

## Technologies

* Python
* Turtle Graphics

## Controls

### Player 1

* `W` — Move Up
* `S` — Move Down

### Player 2

* `↑` — Move Up
* `↓` — Move Down

## Concepts Practiced

* Functions
* Conditional statements
* Loops
* Keyboard event handling
* Coordinate-based movement
* Collision detection
* Turtle graphics
